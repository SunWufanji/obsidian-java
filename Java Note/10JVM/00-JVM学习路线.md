# JVM 学习路线

> 本目录依据飞书《JVM学习指引（体系版）》建立。先理解 Java 程序在 JVM 的内存里怎样运行，再学习 GC、类加载，最后进入调优和故障排查。

## 推荐学习顺序

1. [[01-Java内存区域]]：运行时数据区、栈帧、内存溢出。先回答“一个 Java 程序运行时，数据放在哪里”。
2. [[02-垃圾收集与内存分配]]：引用与可达性分析、垃圾收集算法、收集器、内存分配和回收策略。回答“没用的对象怎样被回收”。
3. [[03-Class文件与类加载]]：Class 文件结构、类生命周期、类加载器和双亲委派。回答“`.class` 文件怎样变成可运行的类”。
4. [[04-JVM调优与故障排查]]：GC 参数、OOM、GC 问题、CPU 100%、死锁。回答“线上 JVM 出问题怎样定位和处理”。

## 大白话总览

JVM 可以先把它理解成 Java 程序的“运行工厂”：

- **内存区域**是工厂里的不同仓库；
- **类加载**是把图纸（`.class`）送进工厂并准备开工；
- **GC**是定期清理没用物料，腾出仓库空间；
- **调优和排障**是在工厂变慢、内存爆满时找原因并调整。
