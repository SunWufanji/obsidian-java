# 并发编程学习路线

> 文件分类参考飞书《并发编程学习指引（体系版）》：先学理论，再学线程基础、锁、容器和线程池。

1. [[01-并发理论基础]]：并发与并行、JMM、`synchronized`、`volatile`、CAS、原子性。
2. [[02-线程基础]]：进程/线程、线程优先级与状态、创建/中断/终止、线程通信、`ThreadLocal`。
3. [[03-常用锁与同步器]]：`Lock`、AQS、`ReentrantLock`、`ReentrantReadWriteLock`、`Condition`、`LockSupport`、栅栏和信号量等协调器。
4. [[04-并发安全容器]]：`ConcurrentHashMap`、`CopyOnWriteArrayList`、`ConcurrentLinkedQueue`、`BlockingQueue`。
5. [[05-线程池与任务框架]]：线程池原理、`Executor`、`ThreadPoolExecutor`、`ScheduledThreadPoolExecutor`、`FutureTask`、`Future`、`CompletableFuture`、Fork/Join 与 `ForkJoinPool`。

建议顺序：先学 01 和 02，理解“为什么会线程不安全”；再学 03 和 04，掌握怎么保护共享数据；最后学 05，学习后端项目如何真正调度异步任务。

> 飞书表格最后的“面试题”是各类知识点的题库入口，不单独建一个重复题库文件；后续每道题仍按上面五类归档。
