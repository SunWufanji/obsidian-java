# Spring 全家桶学习路线

> 本目录围绕 Java 后端常见的 Spring 生态整理：Spring、Spring Boot、MyBatis 与 Spring Cloud。后续以面试题为主线持续补充，同类问题优先合并到原题。

## 模块导航

- [[01Spring/01-Spring核心与Spring MVC]]：Spring 基础、Bean、IoC/DI、AOP、事务、MVC、安全与设计模式。
- [[02Spring Boot/01-Spring Boot]]：自动配置、Starter、配置、Web、数据访问、缓存、异步与运维。
- [[03MyBatis/01-MyBatis]]：执行流程、动态 SQL、缓存、映射与分页。
- [[04Spring Cloud/01-Spring Cloud]]：微服务治理、注册发现、配置、网关、通信、容错与链路追踪。

## 使用约定

- 每份笔记中的独立题目从 `## 1.` 开始连续编号。
- 新内容先检查是否属于已有题目；有新增信息则补充，无新增不重复建题。
